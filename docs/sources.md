# Official source verification

These six enabled feed connectors are the regular collection layer. With the newsroom enabled, a rotating discovery pass additionally uses supported entries in [the approved research catalog](approved-research-websites.md) before concepts are written. New originals become archived context for the planning editor; unsupported registers are not silently treated as functional sources. IFP uses its verified `main[role=main]` article selector; UHP/IEP links are restricted to their analytical-unit paths. An empty feed body can trigger approved HTML extraction, including the previously failing NBS item. See [planned editions and reserve](editorial-workflow.md#planned-editions-and-private-reserve).

Verified with direct HTTP requests and the Java `check-feeds` collector on **13 October 2026**. Availability can change; execute `editorial.ps1 check-feeds` before a production launch. Runtime respects current robots policies and fails a source independently.

MF and MH robots were checked by the Java collector when resolving feeds/body URLs. NKÚ's robots contains restrictions for administrative/API routes; no collector bypasses them. Redirects, authentication challenges and CAPTCHAs are never followed or bypassed. A redirecting source needs an explicitly verified registry update.

To change sources, edit `backend/src/main/resources/sources.json`, ensure the feed URL and allowed HTTPS hosts are real, implement/test a reliable body selector if necessary, run `check-feeds`, then rebuild/redeploy the backend. `Sources` Table stores a registry snapshot and check timestamps; it is not an administrative override endpoint. `init` refreshes snapshots without erasing operational history.

Feeds may have missing/bad dates or URLs. Such entries are skipped. Collection archives available material from the previous 90 days, within the configured run limit and a per-institution share. Only documents from the previous seven days become fresh-news candidates; older documents are context for the analyst. Feed history is finite, so this is not an exhaustive archive. A summary is treated as the actual evidence scope; full documents are never implied when unavailable.
